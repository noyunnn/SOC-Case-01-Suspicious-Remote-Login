# Investigation Report — SOC Case 01

## 1. Incident Overview

- **Incident name:** Suspicious Remote Login Activity
- **Date:** 18 November 2026
- **Affected system:** WS-014
- **Source workstation:** WS-022
- **Source IP:** 10.10.5.23
- **Account involved:** m.ivanova
- **Incident category:** Suspicious Authentication Activity
- **Preliminary priority:** High

## 2. Incident Description

В журналах безопасности Windows обнаружено пять неудачных попыток авторизации с IP-адреса 10.10.5.23.

После этого произошёл успешный удалённый вход на рабочую станцию WS-014 под учётной записью m.ivanova.

Исходная рабочая станция WS-022 принадлежит системному администратору p.smirnov. Учётная запись m.ivanova принадлежит сотруднику бухгалтерии.

Удалённый доступ этой учётной записи к WS-014 не предусмотрен согласно предоставленным условиям учебного кейса.

## 4. Technical Analysis

### Authentication

Пять неудачных попыток входа предшествовали успешной удалённой авторизации.

Logon Type 10 указывает на удалённый интерактивный вход, обычно связанный с RDP.

### Process Activity

После авторизации были зарегистрированы powershell.exe и cmd.exe.

Их запуск требует дополнительного изучения, однако сам по себе не доказывает вредоносную активность.

### File Access

Зафиксирован доступ на чтение файла:

Payroll/November.xlsx

Учётная запись m.ivanova имеет разрешение Read, но не имеет разрешений Write и Modify согласно предоставленным данным.

Изменение документа не подтверждено.

## 5. Findings

Подтверждённые факты:

- Пять неудачных попыток авторизации.
- Последующая успешная удалённая авторизация.
- Использование учётной записи m.ivanova.
- Запуск PowerShell и CMD.
- Обращение к сетевой папке Finance.
- Зарегистрированный доступ на чтение November.xlsx.

Неустановленные обстоятельства:

- Личность человека, выполнявшего действия.
- Причина неудачных попыток входа.
- Было ли подключение согласовано.
- Назначение запущенных команд.
- Наличие передачи данных за пределы организации.

## 6. Risk Assessment

Предварительный приоритет расследования: High.

Основания:

- Необычная последовательность попыток авторизации.
- Удалённый вход с рабочей станции системного администратора.
- Использование учётной записи сотрудника бухгалтерии.
- Последующий доступ к финансовому документу.

При этом доказательств изменения документов или утечки данных пока нет.

## 7. Recommendations

1. Проверить активность и состояние рабочей станции WS-022.
2. Проверить, было ли подключение к WS-014 согласовано.
3. Изучить полные командные строки PowerShell и CMD.
4. Проверить дополнительные события авторизации и удалённых подключений.
5. Проверить активность учётной записи m.ivanova.
6. Передать материалы специалисту SOC L2 для дальнейшего расследования.

## 8. Conclusion

Обнаружена подозрительная последовательность удалённой авторизации и последующего доступа к финансовому документу.

Имеющихся данных достаточно для продолжения расследования, но недостаточно для подтверждения компрометации учётной записи, установления личности нарушителя или факта утечки информации.

**Investigation status: Further investigation required.**
