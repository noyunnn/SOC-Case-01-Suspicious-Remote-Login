 Windows Event Analysis — SOC Case 01

## 1. Authentication Events

### Event ID 4625 — Failed Logon

Зафиксировано пять неудачных попыток входа с IP-адреса 10.10.5.23.

**Аналитическое значение:** повторяющиеся неудачные попытки могут указывать на ошибку ввода учётных данных, неправильную настройку подключения или попытку подбора пароля.

### Event ID 4624 — Successful Logon

В 09:15:01 зарегистрирован успешный удалённый вход на WS-014 под учётной записью m.ivanova.

**Logon Type:** 10 — Remote Interactive.

**Аналитическое значение:** успешная удалённая авторизация после серии неудачных попыток требует дополнительной проверки.

## 2. Privilege Assignment

### Event ID 4672 — Special Privileges Assigned

В 09:16:34 зарегистрировано назначение специальных привилегий сессии.

**Аналитическое значение:** необходимо проверить список назначенных привилегий и контекст учётной записи. Событие само по себе не доказывает повышение привилегий пользователем.

## 3. Process Activity

### Event ID 4688 — Process Creation

Зафиксирован запуск двух процессов:

- powershell.exe — 09:17:02
- cmd.exe — 09:17:18

**Аналитическое значение:** необходимо изучить полные командные строки, родительские процессы и последующую активность. Сам факт запуска этих программ не является доказательством вредоносной деятельности.

## 4. Network Share and File Access

### Event ID 5140 — Network Share Access

В 09:18:41 зарегистрировано обращение к сетевой папке:

`\\FILE-SERVER\Finance`

### Event ID 5145 — Detailed File Share Access Check

В 09:18:43 зарегистрирована проверка доступа к файлу:

`Payroll\November.xlsx`

Операция: ReadData.

Результат: Access permitted.

### Event ID 4663 — Object Access

В 09:18:44 зарегистрирован доступ на чтение объекта:

`D:\Finance\Payroll\November.xlsx`

Операция: ReadData.

Результат: Audit success.

**Аналитическое значение:** данные подтверждают зарегистрированный доступ на чтение файла под учётной записью m.ivanova. Изменение файла не подтверждено.

## 5. Preliminary Assessment

Совокупность событий указывает на подозрительную последовательность удалённой авторизации и последующего доступа к финансовому документу.

Для продолжения расследования необходимо проверить исходную рабочую станцию WS-022, командные строки процессов, контекст удалённого подключения и дополнительные журналы безопасности.

Все сведения являются учебными и смоделированными.
